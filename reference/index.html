一個人的前端團隊

        
元智資傳系畢業，2024 年加入安特庫，是團隊唯一的前端工程師。除了把畫面做出來，我更在意專案能不能長期維護下去。

        
我習慣從使用者的角度想：這個流程好不好用、資料出錯時畫面會怎麼樣。

      

      
    
        
  1. 01一套程式，三種部署公司的資安監控平台要部署成雲端版、落地版、設備監控版三種版本，原本各自維護一個分支。我提出改用環境變數、設定檔和功能開關控制，並實作完成，現在同一套程式就能部署成三種版本。
    2. 
        
  2. 02用 CI 守住品質為排班系統和活動官網建立 GitHub Actions，每次推送程式碼都會自動跑 lint、型別檢查、測試和 build。
    3. 
        
  3. 03把 AI 變成工作方式和 AI 一起整理出「先寫規格、AI 實作、換一個模型審查」的開發流程，寫成文件放進專案，讓之後接手的人也能照著做。
    4. 
      

    


    

      
我擅長

      
    
        
  • 從零建置前端資安顧問平台、AI 排班系統、活動住宿官網，三個專案的前端都由我從零開始建置，從專案架構、頁面到串接 API。其中排班系統搭配 AI coding agent 協作開發。
    •
